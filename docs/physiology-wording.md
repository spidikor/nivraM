# Physiology wording and reported-value contract

Wording updated 11 November 2026. Dataset version `2026-11-11.1` is bundled with matching Python and JavaScript readers. The dataset's original `reviewed_date` and source `accessed_date` values remain historical provenance, not a claim that this change repeated a complete dataset, full-methods, or correction-history review. Correction-review states remain `not_reviewed`; existing `unknown` and absent legacy metadata retain their prior interpretation.

The inspected Bonnet 2019 and DuBose 1983 abstracts report the six saved pH/plus-minus pairs but do not explicitly define their central statistic or plus-minus statistic. These entries now use `statistic: reported_value` rather than asserting a study mean. This records the evidence limitation, not a finding that the values are not means. Their labels and source/preset limitations say the same. No value, uncertainty magnitude, null, sample size, compartment, species, preparation, handling condition, gap, or interval boundary changed.

`reported_value` is a point-only addition to the schema-v1 vocabulary. It requires `display_kind: study_marker`, a finite pH value, and null lower/upper/confidence fields. Unspecified plus-minus values remain unplotted; this enum cannot manufacture an interval. The new readers still accept the existing `study_mean` and `single_condition` point types without rewriting them. Older readers reject the new enum, so the new dataset and readers must be delivered together. This is new-reader/old-dataset compatibility, not old-reader/new-dataset compatibility or a universal schema-v1 compatibility claim.

The explorer, reference chart/table, supplied-model reference lane/list, and their PNG canvas labels identify these as reported values with an unverified central statistic. JSON and typed CSV retain the exact enum, source/preset limitations and unplotted uncertainty metadata. The pre-existing native text-export validators continue to validate their bounded transport contract; this update does not expand them into independent literature validators. Marker geometry, default-disabled overlays, all nineteen contexts and eleven evidence gaps are unchanged. The independently supported CSF mean/confidence interval and arterial reference interval keep their existing statistical meanings and exact endpoints.

The DuBose 1982 interpretation rule and feasibility discussion now distinguish in-situ from equilibrium tubular-fluid pH while making clear that equilibrium pH can also be measured in vivo. Carbon-dioxide handling remains relevant and final-urine overlays remain excluded.

Evidence: [Bonnet abstract](https://pubmed.ncbi.nlm.nih.gov/30590026/), [DuBose 1983 abstract](https://pubmed.ncbi.nlm.nih.gov/6405628/), and [DuBose 1982 publisher PDF](https://dm5migu4zj3pb.cloudfront.net/manuscripts/110000/110425/JCI82110425.pdf), printed pp.146–148. This implementation uses the separately reviewed evidence; no new literature retrieval, statistical reconstruction, or numerical correction was performed. Browser layout and native Windows verification remain deferred. Controlled DOM and canvas-call tests do not establish those results.
