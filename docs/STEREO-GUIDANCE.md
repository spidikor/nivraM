# Unspecified stereochemistry guidance

Local conformer generation still rejects unspecified potential stereochemistry rather than selecting an isomer. Supported RDKit tetrahedral-atom and double-bond targets now return a bounded, source-bound denial diagnostic. Invalid graphs and other failures retain their existing error paths. No new chemistry support or stereo assignment is introduced.

The editor presents the exact headline “Invalid stereochemistry! Please specify”, followed by an explanation that unspecified stereochemistry does not necessarily mean invalid chemistry. Supported flags use grey italic R/S? or E/Z? labels; cis/trans is not substituted. Source atom/bond IDs are retained. Unknown or unmappable stereo types are counted without guessed labels.

The notice is nonmodal. It returns to the drawing while retaining a previous valid generated view. Each flag disappears when its specific atom or double bond is selected; selecting a double-bond endpoint alone does not dismiss that bond's flag. Preselected targets are omitted. Deselection does not restore a dismissed flag. All remaining flags, fallback text and the notice expire at the original 30-second deadline, with visibility/selection checks after resume. Timers are cleared on replacement, document/view changes, dismissal and teardown. A visible “Dismiss stereochemical flags” button clears all guidance, including when the notice has been closed to review the drawing. A fresh generation may display new guidance.

Placement uses actual rendered primitive bounding boxes and measured italic text in canvas coordinates. It tries a bounded deterministic set of directions and distances, checks label/arrow/head obstacles and previous flags, and stops arrows before target ink. Conservative boxes can reject otherwise feasible positions. Dense layouts, unavailable measurements, unsupported targets and clipping produce a named target-list fallback, not knowingly overlapping flags. There is no guarantee that every layout receives a flag.

Guidance is an ephemeral sibling layer: graph, source coordinates, document history, chemical scene, exports and numerical operations are not modified. Pan/zoom or source changes clear placement rather than reuse obsolete geometry.

Validation in the authoring environment is limited to source review, pure Python transport/mapping tests and controlled JavaScript/DOM tests. Native RDKit, Windows and real browser visual qualification remain outstanding.

Fallback text appears in a transient region at the top of the existing inspector. The dismiss control temporarily overlays the existing structure-status footprint, outside the chemical canvas. Underlying status spans retain their layout and continue receiving updates; dismissing guidance restores their visibility without replacing their content. No permanent empty strip is reserved. On narrow screens the visible caption is “Dismiss flags”, with the full accessible name “Dismiss stereochemical flags”. Long fallback lists scroll within the inspector region; no automatic page scrolling moves the user away from the drawing. On mobile the inspector itself can remain below the viewport, while the status-row and popup dismiss actions remain available. Source markup/style and controlled DOM contracts are tested; actual browser responsive geometry remains unqualified.
