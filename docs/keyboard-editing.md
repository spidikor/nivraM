# Keyboard chemical editing increment

The Keyboard drawing panel provides native form controls for currently supported atom, bond and ring construction, entity inspection/selection, movement, deletion, and bond/element changes. One selected atom uses the existing Selected atom charge/isotope controls. Tab leaves the panel normally. Position values are drawing coordinates, not molecular distances.

Pointer and keyboard operations share `public/modules/edit-commands.mjs` and the same candidate validation, chemistry rendering and document/history commit. New bonds preserve the pointer tool's 1.5-unit/30-degree default and optional free positioning. Atom-attached and bond-fused rings reuse existing identity and geometry rules. An unfinished bond captures its starting revision, creates no partial atoms, and is invalidated by document changes, pointer editing, other document operations or close review. Cancel creates no history entry.

Target navigation and the dashed target marker are transient and separate from selection and the molecular SVG used for export. Target options describe atom/bond identities and neighboring atoms. Native controls, explicit focus after Start/Cancel, a polite status region, and modal/composition-aware shortcuts support keyboard operation. This does not establish screen-reader acceptance or physical Windows scaling.
