# Medicinal element palette

The common row contains **C, H, N, O, S, P, F, Cl, Br and I**. The **More ▾**
disclosure contains **Li, B, Na, Mg, Al, Si, K, Ca, Mn, Fe, Co, Cu, Zn, As, Se,
Tc, Ba, Gd, Pt, Au, Bi and Lu**. It reads **More ▴** while open.

This curated set keeps ordinary molecular drawing compact. An element qualifies
through documented use in an active therapeutic or diagnostic agent, including
counterions and historical medicines. Excipient-only occurrences and untested
research compounds do not establish eligibility. The list is deliberately not
an exhaustive inventory of every element that could qualify.

## Interaction and representation limits

Click a common element or open More and choose an element. Enter or Space
activates a focused button. Opening More focuses the currently selected More
element, or the first option. Arrow keys move through options; Home and End move
to the first and last. Escape closes and returns focus to More. Tab and Shift+Tab
leave the disclosure normally. Clicking or focusing outside closes it without
taking focus away from the destination.

The visible palette and keyboard symbol repertoire have different purposes.
Typing a valid element symbol over an atom can address elements outside this
curated set; that is not a medicinal-use claim for those elements.

An available symbol does not guarantee correct representation of every valence,
coordination complex, isotope state, organometallic bond, polymer or formulation.
For example, platinum coordination and gadolinium chelates need appropriate
bonding representations. An integer isotope mass number cannot encode the
metastable nuclear state in Tc-99m. Simethicone's qualification does not imply
support for its full polymeric mixture as one molecular graph. Chemical
validation and supported-format limitations still apply; the editor must not
silently invent unsupported chemistry.
