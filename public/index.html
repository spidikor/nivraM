        nivraM · 0.2.0-dev.1

        A local small-molecule editor. Chemistry runs on your computer. The desktop host provides native project saving and recovery; external scientific requests are off by default. Optional PubChem name lookup requires a separate review and confirmation for every request; core editing remains offline.

        What is implemented

        Atom/bond/ring editing, selection and dragging, history, SMILES/2D MOL import, editable project files, experimental full/partial 2D cleanup preview, native PNG metadata review, and native-resolution PNG export. An optional separate 3D input viewer displays supported supplied-coordinate MOL V2000 and supported V3000 files without changing the drawing.

        Important boundaries

        2D Clean uses the experimental local RDKit backend. Marvin JS layout equivalence remains unverified. The wordmark mirrors the complete literal word Marvin, including glyphs, using a local serif font; fidelity to a specific reference font and wordmark remains unvalidated.

        This development build supports up to 512 atoms. For 2D document import, reaction documents, query atoms, S-groups, 3D input and enhanced AND/OR stereogroups are rejected rather than silently simplified. The separate 3D viewer has its own narrower input limits. Supported V3000 stereo/valence declarations require a fresh bounded native parse-consistency check, which does not verify experimental identity or origin. A separate bounded local generation action uses a copy of the current graph without modifying the drawing. PNG metadata recovery creates an explicitly selected partial reconstruction. Bounded overview and original-resolution crop review are available for supported PNGs. A reviewed crop does not establish that embedded molecular metadata matches that image area. Review drafts support atom, bond, charge and isotope corrections with separate Undo/Redo before acceptance. PNG chooser, drag-and-drop and image paste use the same review. Local MolScribe recognition can propose a structure from a reviewed crop after an existing runtime and pinned model are configured. Model verification does not establish chemical correctness; runtime compatibility is checked when recognition starts. Review chemical drawings before publication.

        PNG export has limits of 128 million pixels, 32,767 pixels per side, and a conservative 512 MiB estimated peak memory budget. Some shapes can exceed the memory budget even below the dimension limits. The app reports an error instead of changing your requested resolution. Default margins are 2% of total width per side.

        3D molecular view

        Inspect supplied coordinates or generate one local conformer from a copy of the current 2D drawing. For PNG input, complete recognition/manual correction and accept the reviewed graph first. A PNG alone cannot establish molecular identity. Your 2D drawing is unchanged.

        Generation: bounded local RDKit model, hydrogens added temporarily during embedding, no energy minimization. Up to 128 source atoms, 256 atoms with hydrogens and 512 bonds in one supported connected molecule. Unspecified potential stereochemistry is rejected rather than silently assigned. See provenance for method and limitations.

        Supplied V2000: 1–256 elemental atoms and up to 512 single/double/triple/aromatic bonds. V3000: 1–128 atoms from H/B/C/N/O/F/Si/P/S/Cl/Br/I and up to 256 single/double/triple bonds. Both require an explicit 3D header. V2000 preserves inline charge codes (excluding radical code 4), fixed-width M CHG (−8 to +8) and absolute M ISO (1–400); M CHG or M RAD replaces the whole inline charge/radical channel. M RAD and V3000 RAD preserve literal codes 0 (none), 1 (singlet), 2 (doublet), 3 (triplet) as unverified declarations, not unpaired-electron counts or verified spin. RAD mixed with CFG/VAL is unsupported. Nonzero inline isotope mass differences remain unsupported. V3000 additionally preserves declared charge (−8 to +8), isotope mass (1–400) and atom map (0–999999). These are unverified declarations, not chemical identities or links to the drawing. Supported V3000 CFG/VAL declarations require fresh local RDKit parse-consistency validation; contradictions and normalized-away declarations reject. Other V2000 properties, ambiguous/enhanced stereo, other properties, queries, SDF, PDB and XYZ are unsupported. An unsupported file is not necessarily an invalid molecule.

        3D PNG recovery reads embedded coordinates, not image pixels. Recovered file claims remain historical and unverified, detached from the current drawing. Export embeds exact MOL coordinates and bounded scientific provenance, recoverable by anyone receiving the PNG.

        Display controls never add hydrogen coordinates or change the source molecule. Slow rotation is off by default and disabled by reduced motion.
